# genjutsu

Skills from [AThevon/genjutsu](https://github.com/AThevon/genjutsu) at commit [`1f518a7`](https://github.com/AThevon/genjutsu/tree/1f518a71378b15d423389e546e767cffc86e14c3), copied into SOYL Hub on 2026-10-29. Licence: MIT.

> Creative coding skills for Claude Code, claude.ai and Cowork. Motion, micro-interactions and design systems across Web (GSAP, Motion, Three.js, CSS), Android (Jetpack Compose) and Apple (SwiftUI). Proposes an interaction thesis you approve before it writes any code. Anti-AI-slop.

All credit goes to the authors of AThevon/genjutsu. Each folder is the upstream skill unchanged, with its licence file added when it had none; build caches and plugin manifests are left out.
