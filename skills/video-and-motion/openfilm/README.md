# openfilm

> The open source AI video agent: turns any coding agent into a video agent, with an editor to change anything it makes.

All credit goes to the authors of openfilm/openfilm. Each folder is the upstream skill unchanged, with its licence file added when it had none; build caches and plugin manifests are left out.
